## 三、已知坑（别再踩）

- **相对路径**：真实会话传 `packages/...` 而非绝对路径；任何新闸必须走 `resolveToolPath(rawPath, exec)`，否则 `statSync` 假阴性 → fail-open。
- **合成参数**：`output_mode/head_limit` 是我早前编的参数，真实 DSH grep 只有 `{pattern,path,include}`。写闸前先用真实会话 `request/header` 核对 schema。
- **clean-a 混淆**：它是 REA 关闭前复制的，已注释 `mcp-client-rea`（备份 `cordis.patch.yml.bak-rea-off-20261019-124440`），**必须重启实例**才生效。
- **`fg_apply` 自证自批**：审核期临时授权会让 L3 全放行；`rm-rf` 已由人工闸门兜住，其余不可逆类别靠红线层（`format-volume`/`drop-database`/`git-push-force`）。
- **熔断是预算触发**：`fused=false` 但 `effectiveCalls ≥ 200` 一样拒；看状态文件里的 `effectiveCalls`。
- **`.ai/` 与 `.focus-guard/` 不入库**：卷宗/审批记录清理只在本机生效。
- **真实 token 只有宿主面板**：会话记录无逐次 usage；台账已由 `usageLooksReal` 守卫停写退化值。

## 四、按主图，下一步该往哪推

主图见 [`ARCH-MAP.md`](ARCH-MAP.md)。当前只剩 4 处红/黄：**L3 隐藏工具（⬜，依赖宿主）**、**L1 画像三件（⬜）**、**L5 反规避两项（🟡）**、**L6 伪 RLHF（🟡）**。

推荐顺序（理由都基于已实测的约束）：

### P0 · 先补数据基线（否则后面所有优化无法验证）
- **3.0.8 面板 ≥5 次**：同 web profile、同 8 任务、禁止重试；记录面板六项 + `steps`/`denies`
- **clean-a 重启后重跑 A 组一次**，得到"只差 FG"的干净对比
- 交付判据：任一百分比能由「3 个面板数 + 1 个 session id + 1 个公式」复算
- 不做这步就动 L1/L6，等于在无基线的情况下调参

### P1 · L1 画像包（`evasionRisk` 先行）
- 现状：`src/profiles/*.mjs` 五份画像，全仓 `evasionRisk` 0 命中
- 做法：先加**纯参数字段**（`evasionRisk: high/low`）→ 接到 `profileLoader` 的审批 scope 判定上（只影响 `IRREVERSIBLE_IDS` 之外的类别），不引入新判定层
- 验证：`test:all` + `bench:decision`（画像组已有 f1-f4 用例可直接扩）
- 暂不做"相位对抗 A/B/C"与"Nudge 缓冲垫"：它们需要 KV 缓存盲区实验数据，当前没有测量手段，先记入 `ARCH-MAP` 缺口

### P2 · L6 伪 RLHF 回流（把测量接回参数）
- 现状：`bench:ab` / `bench:tasks` / `bench:cost` 已能测，但**结论不回写**
- 做法：人工批准制的小闭环 —— `bench` 输出 → 生成 `docs/PROFILE-TUNING.md` 建议条目 → 人工确认后改 `src/profiles/*.mjs` → 再跑 `bench:decision` 对比
- 明确不做自动调参（无人批准的回流等于自证自批，与 L3 人工闸门精神冲突）

### P3 · L5 反规避参数化（小而独立）
- 「2-5 次随机熔断」：用独立参数（如 `FG_RANDOM_FUSE_EVERY`），与 `RANDOM_AUDIT_EVERY` 分开，避免和抽查逻辑耦合
- 意图预警：`stalledStreak`/`ineffCalls` 已有计数，补"重复试探同一目标 3 次 → 提示换策略"的**提示**（不升级为 deny）

### P4 · L3 隐藏高危工具（等宿主）
- 现状：schema 由宿主注入，FG 改不了；等价替代已做（默认只读 + 按需解锁）
- 需要宿主提供**工具延迟加载/按任务暴露**接口；在此之前唯一能做的是把 `FG_PTC_READONLY` 默认打开——**这是行为变更，须人类批示**，不在下一次会话默认执行

### 不建议现在做的
- 「相位对抗 A/B/C」：没有 KV 盲区测量手段，做了无法验证
- 「L7 工作流代码化」：目前靠指令级约束已够用
- 发布 3.0.8 到 npm：版本面已就绪，等人类决定（发 AGPL 版即不可回退）
