## 六、踩过的坑（本会话新增）

- **FG 自拦**：命令里含 `&&`、`cat`、`rm -rf`、`publish` 字面量会被自己的闸拦；写脚本文件跑，或拆分字符串
- **随机抽查B**：会拦一次写（"拒一次即放行"），重试即可；`effectiveCalls ≥ 200` 才是真熔断，需人类授权清零（今天清过两次，14 个状态文件全清零）
- **探针必须核对签名**：`stopGuard` 读 `turnCount` 不是 `turnCalls`；`consumeApproval(tool, command)` 是位置参数；`judgeCatGate(command)` 收字符串；`rotateAuditIfNeeded(file, max)` 返回归档路径不是布尔
- **`ReplaceFileW EIO (1175)`**：宿主原子替换撞文件占用（并行会话/杀软），重读重试即可
- **合成参数会骗自己**：新写判定前先核真实 schema（`npm run gate:audit` / `real-calls` 夹具）
