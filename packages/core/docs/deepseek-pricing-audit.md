## 一、峰谷时段定义（官方原文）

- **高峰时段**：北京时间周一至周五（不含中国法定节假日）9:00-12:00、14:00-18:00
- **空闲时段**：其余所有时段，包括周末及中国法定节假日全天
- **计价关系**：空闲时段价格为高峰时段价格的一半

## 三、与 dsh-peak-cost-mode 现有常量的偏差

任务书结论：该插件的峰谷判定和价目表**存在严重偏差**（本阶段不拉取其源码，未逐条比对常量；收编后以其职能退役为准）。已按官方口径重写以下易偏差点，供后续 diff 该插件时对照：

1. **节假日表过期**：本模块硬编码 2026 全年 33 天（国办 7 号文）；峰谷插件如内置 2025 表即全年错档。
2. **无调休上班日处理**：调休周六/周日按"周末=谷"处理会少计费——本模块对调休日保守按工作日。
3. **空闲≠高峰一半**：官方规则明确减半，任何独立成表的价目都可能与减半规则漂移——本模块价目直接内置两档，不做运行时换算。
4. **时段边界与时区**：窗口按北京时间分钟制 [9:00,12:00) 与 [14:00,18:00)（左闭右开），判定与宿主机器时区无关。
