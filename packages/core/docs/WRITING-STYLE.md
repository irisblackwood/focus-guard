# 写作与排版规矩

> **状态**：权威 · 适用版本 3.3.0 · 最后核对 2026-10-28

> 起因：2026-10-27 人类两次批示「讲一点格式啊，排版一点没有」「你这乱的，都要丢给模型才能读明白」。
> 适用：`CHANGELOG.md`、`docs/*.md`、`README*.md`、**以及对话回复**。
> 一句话：**写给人扫的，不是给模型解析的。**

## 一、先量，再定规矩

`CHANGELOG.md` 实测（237 条条目，改前）：

| 指标 | 实测 | 可读上限 |
|---|---|---|
| 条目平均字数 | **220** | 120 |
| 超 200 字的条目 | **97 条** | 0 |
| 超 400 字的条目 | **35 条** | 0 |
| 最长条目 | **865 字** | 120 |

一条 bullet 865 字，等于把一篇短文塞进列表项。人眼扫列表时每项只给两秒，
超过三行就跳读——**跳读等于没写**。信息没丢，读者丢了。

## 二、七条规矩

| # | 规矩 | 为什么 |
|---|---|---|
| 1 | **首句给结论**，不铺垫背景 | 读者扫第一条就决定要不要往下看 |
| 2 | **条目正文 ≤ 120 字**，超出拆子项 | 两行内能扫完 |
| 3 | **有标签子项 ≤ 150 字；裸写子项 ≤ 80 字** | 标签让读者能跳读，裸写没有抓手必须短 |
| 4 | **层级最多两层**（`- ` 与 `  - `） | 第三层人眼分不清归属 |
| 5 | **三个以上同类项上表**，单元格只放短语 | 表格横向对比，段落纵向堆叠 |
| 6 | **论证进 HANDOFF，不进 CHANGELOG** | 见第三节 |
| 7 | **段标题已含的信息，条目内不重复** | 29 条各写一遍 `（2026-10-27）` 是纯噪音 |

### 子项用粗体标签开头

同一段里，子项的首词固定成一组标签，读者靠它决定跳过哪条：

```
- **原因** / **依据** / **代价** / **改动** / **回退** / **测试** / **影响** / **局限**
```

没有标签的子项，读起来又是一坨。**标签本身是排版，不是装饰。**

`①`–`⑨` 编号与粗体标签同权——都是「一眼能定位」的结构标记。
判据只认形式：**开头有结构标记，可以写到 150 字；没有，就必须在 80 字内收住。**

### 一段超过 8 条就分组

`### 闸门行为` / `### 测试基础设施` 这类三级小标题，让读者能按主题跳读。
29 条平铺时，第 20 条和第 3 条看起来一样重要——**分组就是在告诉读者哪些是一类**。

## 三、第 6 条是根因

`CHANGELOG` 回答**「变了什么」**，`HANDOFF-*.md` 回答**「为什么这么变」**。

两者混写，产物就是「一条 865 字的 bullet」——它对写作者顺手（想到哪写到哪），
对读者灾难（要先读完论证才知道结论）。

| 文档 | 读者 | 每条该有 | 不该有 |
|---|---|---|---|
| `CHANGELOG.md` | 使用者 / 升级者 | 变了什么、要不要动 | 审计原始数字、被否决的方案 |
| `HANDOFF-*.md` | 下一个接手的开发者 | 根因、证据、试错过程 | —— |
| `docs/*.md` | 查规则的人 | 定义、判据、例外 | 某次事故的完整复盘 |

**但删论证有前提**：先确认它已在 HANDOFF 或 commit message 里落地。
2026-10-27 实测「熔断只活一步」这类条目**在 HANDOFF 里只有零散提及**，
所以那次没有硬删，而是**拆成子项**——先让可扫，再谈瘦身。顺序不能反。

## 四、判据

| 判据 | 阈值 | 校验方式 |
|---|---|---|
| 条目字数 | ≤ 120 | `tests/changelog-format.test.mjs` |
| 子项字数 | 带 `**标签**`/①-⑨ ≤ 150；裸写 ≤ 80 | 同上 |
| 嵌套深度 | ≤ 2 | 同上 |
| 段落字数（非列表正文） | ≤ 300 | 人工 |

存量超标用**棘轮**：把当前最差值写成上限，只许降不许升。
一次性清到零不现实，而「永远红的闸门」等于没有闸门（`schema:verify` 上踩过）。

2026-10-27：全部 21 个版本段已按上表重排，棘轮 **753 → 120**；同时修掉一个审计盲区——
3.0.6 及更早的 16 个段标题没有 `· YYYY-MM-DD`，旧切段正则把它们整段跳过，
"零违规"与棘轮对它们一直是空转。现日期可选，所有 `## x.y.z` 段都进审计。
子项条数不再设上限：实测带标签的子项靠标签跳读，限制条数会把结构压回"一坨"。

## 五、对话回复（不可机械校验，靠自觉）

| 毛病 | 改法 |
|---|---|
| 一次讲五件事 | 先给结论清单，再逐条展开 |
| 段落五到八行 | 拆到三行以内 |
| 长枚举塞进句子 | 上表 |
| 复述工具输出 | 只报结论 + 锚点（`文件:行号`） |
| 先讲背景再讲结论 | 反过来 |
| 全程一个层级 | 标题分段，每段一个主题 |

判据一句话：**读者能不能只看标题和表格首列就明白发生了什么。**
不能，就是排版没做。
