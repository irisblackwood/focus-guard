## 四、已知坑（别再踩）

- **熔断是预算触发，不是标志位**：`fused=false` 但 `effectiveCalls ≥ 200` 一样拒；要看状态文件里的 `effectiveCalls`。
- **FG 的闸只覆盖"工具 + shell 写目标 + 变更型 shell"三条入口**：新加判定时务必三条都覆盖，否则又是绕过口。
- **A/B 对照必须在干净卷宗下做**：卷宗【三】的取证记录会让"未读即改"放行（它不参与取证闸判定，但会影响人类对结果的解读）。
- **`.ai/` 是 gitignored**：卷宗清理只在本机生效，别指望提交。
- **真实 token 只有宿主面板有**：会话记录无逐次 usage，FG 台账写的是退化值（已加守卫停止写假账）。
- **改 profile 配置要重启 Desktop**：MCP 进程在启动时建立。
