## 一、两个版本，不是同一个东西

| 入口 | 网格来源 | 产物 | 在版本库里吗 |
|---|---|---|---|
| `npm run brain` | 程序化沟回 + 法线光照 | 约 481 KB | **在**，clone 即可跑 |
| `npm run brain:cosmic` | 真 PLY 皮层网格 | 约 6.3 MB | **不在**，本地实验产物 |

`brain:cosmic` 的生成器与皮层数据都在 `.focus-guard/viz/` 下，而该目录在 `.git/info/exclude` 的私有面里。
数据来自 `memory-brain`，许可为 CC BY-SA 3.0——把它请进公开仓库，等于替每个使用者接下一份传染性授权，
这个决定不该由工具替人做。所以 `brain-cosmic.mjs` 的边界是：**资产不在就明说，不装崩溃**，
`exit 1` 并指向 `npm run brain`。

**第一次跑是空的，这是对的。** 新装没有足迹，脑的形状由沟回与法线光照撑住，不靠记忆点亮；
跑几次让 guard 记下动作，足迹与连线才长出来。头部如实报「实读几份文档、缺几份」——
`self-improvement/` 与 `.ai/` 是私有面，别人 clone 下来本来就没有，缺是正常的。

## 二、背景：程序化星空

零外部资源，全部着色器生成：会闪的恒星 + 银河带 + 三团彩色星云 + 两台黑洞。

黑洞按真东西画，不是画个黑圈加光晕：

- 盘**侧对**（离侧对 11°）——正视的盘看不出多普勒不对称，那才是最容易辨认的特征；
- 薄盘温度走 **Shakura–Sunyaev** 剖面（T ∝ r^(−3/4)），颜色由温度经**黑体**转 RGB，不是手调色；
- 亮度 ∝ **g⁴**（多普勒 × 引力红移的合成因子），两侧亮度差约 **80 倍**；
- 中间那块黑是「这个方向不撒星」撒出来的**真遮挡**，不是叠一层黑圆；
- 顶上那道弧是引力弯折后的**次级像**。

几何取自 `sundyme/event-horizon`，但**积分器没抄**——它每像素几百步光线步进，
我们是 30 ms 预算里的背景，用不起。

## 三、draw call 拆分

星空拆**两个** draw call：

| 层 | 内容 | 处理 |
|---|---|---|
| 锐点 | 恒星 | 走假 bloom |
| 雾点 | 银河 / 星云 / 盘面 / 外晕 | 只走一遍，不做 bloom |

判据是**填充率**：对本来就软的大点再做 bloom，只是把同一片像素重复烧一次，视觉上没有增量。

## 四、`?stars=0` 是什么

**性能 A/B 用的对照臂，不是给用户的功能开关。** 关掉星空后测同一段场景，
实测 **31.2 ms vs 20.1 ms**（软件渲染口径）——这个差值是「背景值不值这个预算」的唯一证据。

它出现在 URL 里而不是设置项里，就是为了让它**不像功能**：没人会在设置面板里
找「关掉星星」，但做性能对照的人需要一个可复现的开关。

> 数字口径提醒：31.2 / 20.1 是**软件渲染**（无 GPU 加速）下的单帧耗时。
> 有 GPU 时两者都远低于此，这个比值不能直接搬到硬件渲染上。
