## 一、一个脚本，三种跑法

`tools/brain-cosmic.mjs` 是唯一入口，差别只在参数：

| 命令 | 行为 |
|---|---|
| `npm run brain` | 自动选档：有皮层生成器就用皮层版，没有就模板版；渲染完打开浏览器 |
| `npm run brain:build` | 同上，不打开（脚本 / 无桌面环境用） |
| `npm run brain:cosmic` | **强制**皮层版（`--strict`）：没有生成器就报错 exit 1，不静默退回 |
| `npx focus-guard-brain` | 与 `npm run brain` 等价（`bin` 指向同一脚本） |

**判据是 `.focus-guard/viz/build-brain2.mjs` 在不在**，不是 `assets/cortex.bin` 在不在——两者都在时，走的是皮层版。

| 档 | 触发条件 | 脑壳 | 背景 | 产物 |
|---|---|---|---|---|
| 皮层版 | 生成器在 | 真 PLY 网格（`lh.pial.ply` / `rh.pial.ply`）+ three.js 光照 | 星空 + 双黑洞 | 约 6.0 MB |
| 模板版 | 生成器不在，`assets/cortex.bin` 在 | 皮层点云 27,638 点 | 纯黑 | 约 0.8 MB |
| 退化解 | 两者都不在 | 解析椭球 + 程序化沟回 | 纯黑 | 约 0.5 MB |

**数据只有一条链**：`brain.mjs --data-only` 更新索引与 `brain-data.json` → 渲染器读它出图。
以前不是这样——皮层版读的 `brain-data.json` 没有任何脚本在写，是某次手工导出的快照，
审计日志天天长而它的节点停在导出那天。看着最顺眼的那版，恰恰是唯一不接活数据的。
现在三档永远是同一颗脑，区别只在网格与背景。

### 为什么皮层版是「本地实验产物」

`build-brain2.mjs` 与它读的 `brain-mesh-pial/pial_Full_ply/*.ply`（左右各 9.3 MB）都在
`.focus-guard/viz/` 下，**不入版本库**，所以 clone 或 `npm i` 的机器上通常没有它们——
这不是缺陷，是刻意：真 PLY 是 CC BY-SA 3.0，本仓代码是 AGPL-3.0-only，两者不兼容，
请进公开仓库等于替使用者接下一份传染性授权。

`assets/cortex.bin` 是它的降采样产物（189 KB，27,638 点），放在 `assets/` 下
**按 CC BY-SA 单独授权**，与代码**并列分发**（mere aggregation）——3.5.0 起已列入 npm `files`，
两条安装路径拿到的资产一致。条款与署名见 [assets/NOTICE.md](../assets/NOTICE.md)。

缺资产时**回退而不是报错**：用户要的是「看到脑」，不是「知道有个更高级的版本自己装不起」。
只有 `brain:cosmic`（`--strict`）会硬失败，因为那是「给有资产的人确认用」的入口。

**第一次跑是空的，这是对的。** 新装没有足迹，脑的形状由网格与沟回撑住，不靠记忆点亮；
跑几次让 guard 记下动作，足迹与连线才长出来。头部如实报「实读几份文档、缺几份」——
`self-improvement/` 与 `.ai/` 是私有面，别人 clone 下来本来就没有，缺是正常的。

## 二、脑壳：为什么必须是真网格

模板版早期用 `cortexAt()` 算脑形：三个数学函数拼一个椭球，加 0.022 的噪声起伏。
它和真皮层版摆在一起，**一眼就是两个东西**——不是背景有没有星，是脑壳不是同一副。

现在 `brain-view.html` 优先读 `assets/cortex.bin`（FreeSurfer pial 表面降采样）。
两个关键细节：

- **沟深靠几何，不靠噪声**：每点带一个 `grv`（法线·径向的夹角，1 = 回顶、0.25 = 沟底），
  `emit()` 用它压暗沟底。点云没有法线也没有光照，几何凹下去在稀疏点里读不出来，
  必须再给一层明暗——但**只动颜色不动透明度**，降 alpha 会变成"洞"，那是缺数据的样子。
- **厚度带必须窄**：`emit()` 曾按 `0.80 + 0.20·rnd()` 向心内收，径向随机量 0.20 比沟深还大，
  刚刻出来的褶皱当场被抹平。网格版收到 3%，解析版 10%。
- **小脑与脑干的锚点由网格给**：`pial` 只覆盖大脑皮层，这两块始终是解析几何。
  它们的挂载位置取"后下方那一片的重心"，不是我拍一个常数——真皮层下缘比椭球低，
  照旧常数挂会悬在半空、裂出一道黑缝。

## 三、背景：程序化星空（仅皮层版）

零外部资源，全部着色器生成：会闪的恒星 + 银河带 + 三团彩色星云 + 两台黑洞。
实现在 `build-brain2.mjs` 内联的 GLSL（片段来源为同目录的 `garg-geo.frag` 与 `sun-ref.html`），
模板版没有这一层。

黑洞按真东西画，不是画个黑圈加光晕：

- 盘**侧对**（离侧对 11°）——正视的盘看不出多普勒不对称，那才是最容易辨认的特征；
- 薄盘温度走 **Shakura–Sunyaev** 剖面（T ∝ r^(−3/4)），颜色由温度经**黑体**转 RGB，不是手调色；
- 亮度 ∝ **g⁴**（多普勒 × 引力红移的合成因子），两侧亮度差约 **80 倍**；
- 中间那块黑是「这个方向不撒星」撒出来的**真遮挡**，不是叠一层黑圆；
- 顶上那道弧是引力弯折后的**次级像**。

几何取自 `sundyme/event-horizon`，但**积分器没抄**——它每像素几百步光线步进，
我们是 30 ms 预算里的背景，用不起。

## 四、draw call 拆分

星空拆**两个** draw call：

| 层 | 内容 | 处理 |
|---|---|---|
| 锐点 | 恒星 | 走假 bloom |
| 雾点 | 银河 / 星云 / 盘面 / 外晕 | 只走一遍，不做 bloom |

判据是**填充率**：对本来就软的大点再做 bloom，只是把同一片像素重复烧一次，视觉上没有增量。

## 五、`?sulc=0` 与视角参数

模板版（`brain-view.html`）认四个 URL 参数：

| 参数 | 默认 | 作用 |
|---|---|---|
| `?sulc=0` | 开 | 关掉程序化沟回，对照「解析椭球比真网格差多少」 |
| `?ax=` / `?ay=` / `?az=` | 0.84 / 0.56 / 1.0 | 视角 |

它们出现在 URL 里而不是设置项里，就是为了让它们**不像功能**：没人会在设置面板里
找「关掉沟回」，但做对照的人需要一个可复现的开关。

> **历史**：2026-11 之前还有一个 `?stars=0`（关星空，用于测背景值不值帧预算）。
> 皮层版改用独立生成器后，该开关随旧模板一起移除，当时的对照数据已无法复现，故不再引用。
