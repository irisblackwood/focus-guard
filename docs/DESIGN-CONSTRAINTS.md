## 四、逐条

### C1 算术/时序二分

- **约束**：抑制按计算功能分两类——**算术**（增益控制、归一化）与**时序**（平衡、锐化、去相关）。
  算术类里必须用**除法降斜率**，不用**减法平移阈值**。
- **失效模式**：只做减法 → 响应曲线整体平移，历史裁决全部不可复算；只做算术不做时序 → 近重复输入被当成独立证据。
- **原文依据**：抑制模体数「至少与细胞类型数一样多」，不存在固定的三种；增益控制可「either by decreasing the slope divisively or by a subtractive shift」。
- **判据**：三种模体各自存在——前馈（红线，多条件同时满足）、反馈（按活动量累计）、去抑制（临时关掉抑制）；且调参走除法不走减法。
- **当前**：有前馈与去抑制，**缺反馈**。
- **去抑制不是放宽**：`grants.mjs` 的一次性授权是局部、临时、留痕的；改阈值是全局、持久、不可回放的。两者不可互换。

### C2 门控抑制

- **约束**：常规调用走廉价通道，只有异常进完整链路；门控是**抑制大多数**，不是中继所有。
- **失效模式**：全量过闸 → 每个调用的成本相同，异常占比被稀释，响应变慢而精度不升。
- **判据**：存在一条「低成本前置筛」，且放行决策仍是确定性的（可重放）。
- **容量锚点**：工作记忆上限约 **4 个组块**。流传的 7±2 不是容量上限——原文说它「was meant more as a rough estimate and a rhetorical device」。
- **先定义组块，再谈条数**：「Capacity limits will be useful … only if the **boundary conditions** for observing them can be carefully described.」一条决策算不算一个组块，得先定。
- **当前**：`PRE_STAGES` 八段串行，无前置筛。

### C3 稀疏分离

- **约束**：相似但结论相反的事件，必须在**编码层**分开，不能靠人事后读日志分。
- **失效模式**：共用同一个 `trigger` 桶 → 误伤计数与真拦计数混在一起 → 学习把危险一起放宽。
- **判据**：计数键的粒度细于规则名，至少包含命令形态指纹。
- **当前**：`trigger` 只有规则名粒度（`volume:kb`、`whole-file:lines`）。

### C4 标记与稳态分离

- **约束**：给单条事件打价值标记，与维持系统整体平衡，是两条独立通路。
- **失效模式**：两者共用一个阈值 → 调稳态会改变单条判定，误伤与松紧无法分开归因。
- **判据**：标记通路不写阈值，稳态通路不改单条结论。
- **当前**：L5 语义信号（标记）已独立；稳态通路不存在，故未冲突。

### C5 只调元参数

- **约束**：学习只改**元参数**（探索温度、学习率、折扣、误差信号），不改判定规则。
- **出处强度**：对应关系原文用「**may correspond**」，且二手引述只列三个调质（血清素、去甲肾上腺素、乙酰胆碱）；多巴胺＝TD 误差另有来源。**这是十一条里推测性最强的一条。**
- **失效模式**：裁决直接改规则 → 同一条命令在不同时刻结论不同，审计无法回答「为什么被拦」。
- **判据**：申辩通路只开授权，不写规则。
- **当前**：`fg_appeal` 走 `grants.mjs` 一次性授权，规则零改动——**这条已满足**。
- **缺口**：裁决结果不累积。同一形态二次误伤仍要再申辩，学习量为零。
- **精确化：调斜率，不调阈值**。调阈值会让同一命令的历史裁决不可重放（当时该拦、现在该放）；调斜率只改变收敛快慢，历史仍可复算。
- **原文依据**：增益控制有除法与减法两种形式，减法即「平移阈值」，是这里明确排除的那一种。
- **累积的形态**：不是在线加一，是**离线重放时的频次**。一次会话只发生一次，而「学会」需要多次重放；在线计数器会把偶发误伤当成规律。

### C6 一致性监测

- **约束**：两路判定结论不一致时，必须留下记录，即使不影响决策。
- **失效模式**：串行短路（第一个 deny 即返回）→ 「红线说危险、语义说没事」永不出现 → 误伤无法在事后被发现。
- **判据**：deny 之后仍跑影子判定，结果只写审计、不进决策链。
- **当前**：`pipeline.mjs` 的 `for` 循环遇 verdict 即 `return`，无影子通道。

### C7 时间基准

- **约束**：重估时机由**节律**决定，不由事件计数决定。
- **失效模式**：只用「多久没变」→ 系统忙时频繁重估、闲时长期不估，节律随负载漂移。
- **判据**：存在与事件无关的时间基准，或明确声明「以事件计时代替节律」并接受漂移。
- **当前**：自适应 TTL（6h 起翻倍）是事件计数型，已声明语义为「观察到多久没变」。**接受漂移**。
- **两档时间常数**：同一参数需要会话内（分钟级，随会话销毁）与跨会话（小时到天级，落盘）两个常数。只有一档时，短期波动会污染长期状态。

### C8 条件重写

- **约束**：没有「预测误差」就不重写。读操作在内容未变时不得产生写。
- **失效模式**：无条件写回 → 每次读取放大一次。转义膨胀是实例：`cell()` 转义、`uncell()` 只归一不解转义，跑几十次到 347 MB。
- **原文依据**：再巩固需要预测误差——「prediction error is necessary to induce reconsolidation-like effects」；没有误差的提取不使记忆变脆弱，也就不重写。
- **判据**：① 内容未变时读操作零写入（mtime / 字节数可验）；② 必须写时幂等（连存三次体积不变）。
- **当前**：部分。幂等已有（`cell()` / `uncell()` 配对 + 夹具）；**「无变化不写」未做**。
- **为什么两条都要**：幂等是「写坏了能自愈」，条件写是「压根不写」。后者更省，也更安全。

### C9 提取抑制竞争者

- **约束**：遗忘是**主动**过程——提取时抑制未被选中的竞争项，不靠条数上限被动截断。
- **失效模式**：只做精确去重 + 条数上限 → 十条里塞八条近重复表述，关键决策被挤出，而每条看起来都不重复。
- **原文依据**：遗忘「arises when other competing traces interfere with retrieval, and inhibitory control mechanisms are engaged to suppress the distraction」，且「considered adaptive because it reduces future interference」。
- **判据**：一次检索后，未被选中的近竞争条目**降权**（不注入、不删除），且降权可恢复。
- **当前**：未实现。`clean()` 是 `Set` 精确去重；`repeatGuard` 拦命令重复，不合并记忆条目。
- **为什么不是合并**：合并丢信息且不可逆；抑制只降权，检索条件变了还能回来。
- **为什么不能只靠上限**：上限是**数量**约束，干扰是**语义**问题。加条数只是把损失推迟。

### C10 巩固通道

- **约束**：情景记忆（带时空索引的一次性记录）必须有到语义记忆（去情境、可复用）的提炼通道。
- **失效模式**：只有情景层 → 卷宗无限增长，每次会话重读原始记录，成本线性；只有语义层 → 丢可追溯性。
- **判据**：一条离线路径把 N 条情景提炼成 M 条语义（M<N），且每条语义可回溯到来源。
- **当前**：未实现。M2 只建索引（导航），不做提炼（压缩）。
- **为什么离线**：提炼要重放全量日志，进运行时链路就是把成本压到每次判定上。
- **原文依据**：巩固是「replay … in a **compressed format**」后「transferring this compressed representation to distributed circuits」；情景「**may occur only once**」而重复由「repeated and compressed replay」提供。
- **原文依据（算子）**：脑的计算算子清单里**没有「记忆存储」，只有 `compression` 与 `hash coding`**。巩固是压缩，不是保存。

### C11 前缀分歧点

- **约束**：易变内容不进前缀；必须进时，放在所有稳定内容之后。审计要记**首个分歧点位置**，不只记「变了」。
- **失效模式**：易变内容（时间戳、会话 id、计数器、历史）出现在前缀前部 → 从该点起缓存全部失效 → 每次调用重新 prefill。
- **原文依据**：KV 缓存依赖**精确 token 前缀**，分歧点之后失效、之前仍复用；「longest-shared-prefix-first order is equivalent to a depth-first search order」可达最优命中率。
- **判据**：审计行含首个分歧点的段名与字节偏移，使「谁造成的前缀抖动更靠前」可排序。
- **当前**：部分。`prefixStability.mjs` 有整段指纹与 `prompt-prefix-shift` 审计，但只记「变了」，不记分歧点位置。
- **为什么位置比布尔值重要**：分歧在第 10 字节与第 10000 字节，损失差三个数量级；只记「变了」排不出修复优先级。

## 五、零件 → 约束（转换规则）

脑区清单的用法是**提取约束后丢掉零件**，不是按零件建模块。

| # | 规则 | 理由 |
|---|---|---|
| 1 | 一个脑区只提一种计算 | 解剖分区不等于功能分区 |
| 2 | 落进已有类 → 丢弃 | 第二十个实例不产生新约束 |
| 3 | 落进新类 → 先问失效模式 | 说不出就是比喻 |
| 4 | 解剖相连的环路不许拆成两个模块 | 拆开后两个都失效（基底节-丘脑-皮层） |
| 5 | 禁止按脑区命名模块 | 命名固化形状，形状会过期 |
| 6 | 细胞机制只改判据，不新增约束 | 它能改的是「怎么判」，不是「判什么」 |
| 7 | 记忆机制按「层」提，不按「区」提 | 情景/语义/程序/工作记忆是四种机制，不是四个脑区 |

**实测比例**：50 个脑区归入 7 类，其中 39 个是已有类或别名，5 个析出 C6/C7。
**边际收益在第 40 个之后接近零**——这是「不扩充清单」的依据。

**记忆层单独产出 2 条**（C9/C10），**神经元层产出 0 条新约束**、只精确化了 C1/C5/C7 的判据。
方向相反：越往「层」（机制）走越有产出，越往「区」（零件）走越没有。

## 六、明确不做

| 不做 | 理由 |
|---|---|
| 审计日志加时序权重 | 证据链是集合不是权重向量，无消费者；要的是三种抑制，不是 STDP 加权 |
| 自由能作为目标函数 | 无可证伪性，且无生成模型可算 |
| 并行竞争 + 点火式仲裁 | 差一票全输不可重放，违反验收标准 |
| 按 50 脑区建 50 模块 | 零件表不可收敛，见第五节 |
| 左右半球双脑投票 | 分裂决策，重放时无法复现 |
| 突触级仿真（权重、脉冲、毫秒配对） | 本仓没有可塑权重，也没有毫秒级事件对；仿出来的只是形状 |

## 七、神经元层的结论：只细化，不新增

细胞层能提供三样东西，但**没有一样构成新约束**，它们各自落进已有类别：

| 机制 | 落点 | 得到的判据 |
|---|---|---|
| 抑制的算术 / 时序二分 | C1 | 算术走除法不走减法；三种模体各自存在 |
| 增益调制（改斜率，不改驱动输入） | C5 | 调斜率不调阈值，历史裁决才可重放 |
| 突触可塑性多时间尺度（秒级 / 天级） | C7 | 同一参数需要会话内与跨会话两档常数 |

**判据**：一个细胞机制如果只能改变「权重」，而本仓没有权重，它就不进本页。
**唯一例外**是它改变了「有几种东西」——算术/时序二分就是这样进来的，它把「抑制」这一个东西数成了两类。

## 八、理论地位

- **理论是脚手架**，不是物理学。不可证伪的框架只能提供**设计约束**，不能提供**验收标准**。
- **验收永远是工程指标**：误伤率降没降、审计能不能重放、崩了能不能恢复。
- **允许理论错**：某条约束被工程证伪时，改约束不改验收标准。

| Buzsáki 2015，《Hippocampal sharp wave-ripple》，Hippocampus 25:1073–1188 | 巩固＝「replay … in a compressed format」后「transfer to distributed circuits」；情景「may occur only once」而重复由「repeated and compressed replay」提供 | C10 定为「压缩+转移」；C5 的累积改为离线重放频次 |
| Hulbert & Anderson 2015，《Retrieval induces adaptive forgetting of competing memories》，J Neurosci | 遗忘「arises when other competing traces interfere with retrieval, and inhibitory control mechanisms are engaged to suppress the distraction」；「adaptive because it reduces future interference」 | C9 从「相似度合并」改为「提取时抑制竞争者」 |
| Ferrara 2023，《Memory retrieval, reconsolidation, and extinction》，Front Synaptic Neurosci | 再巩固需要**预测误差**——「prediction error is necessary to induce reconsolidation-like effects」；无误差的提取不使记忆变脆弱 | C8 从「幂等写」升级为「条件写」 |
| SGLang 2024（arXiv:2312.07104） | KV 缓存依赖**精确 token 前缀**，分歧点之后失效、之前仍复用；「longest-shared-prefix-first order is equivalent to a depth-first search order」；吞吐最高 6.4× | 新增 C11；指出只记「变了」不够，要记分歧点位置 |
| Cowan 2001，《The magical number 4 in short-term memory》，Behav Brain Sci | 「7±2」是「a rough estimate and a rhetorical device」；单一中央容量上限「averaging about **four chunks**」 | C2 得到容量锚点；且强调先定组块边界再谈条数 |
| Damasio 1996（摘要） | 标记信号「arise in **bioregulatory processes** … not necessarily confined to emotions」；作用于多个层级 | C4 依据从「转述」升为「摘要」 |
| Botvinick 2001（摘要） | ACC「monitoring for conflicts」，且冲突信号**触发补偿性调整** | C6 增加「影子判定可作调整触发源，但不改当次决策」 |
| Hastings 2018（摘要） | SCN 离体培养下「autonomous timing mechanism can persist indefinitely」 | C7 依据升为「摘要」；**节律自己走，不等事件** |
| Ishii 2002（引述 Doya） | 元参数「**may correspond** to neuromodulators such as serotonin, noradrenaline and acetylcholine」 | **C5 从「四类调质」降为「三个 + 多巴胺另有来源」，且是推测非定论** |

**方法上的收获**：三篇里有两篇在**否定整齐的分类**——Tremblay 说分类未完成，Kepecs 说模体数不固定。
分类本身不稳定，正是「不许按零件建模块」最硬的理由。

**另一条收获**：两篇（Granger、Buzsáki）都把「记忆」说成**压缩**，没有一篇说成「存储」。
工程上「记忆模块」这个词本身就是错的——它该叫「压缩通道」。

## 十一、按功能组织：到底能优化什么

前九节是「理论 → 约束」，是自外向内看。这一节反过来：**从现有功能出发，看理论能不能让它更好**。

| 现有功能 | 现在怎么做 | 理论 | 优化成什么 | 收益 |
|---|---|---|---|---|
| 卷宗写回 | 每次 load→save **无条件**写 | C8 条件重写 | 内容哈希未变则跳过写 | 省 IO，根除转义膨胀 |
| 申辩裁决 | 批一次开一次授权，用完即忘 | C5 累积 + C8 | 同形态批过 N 次 → 下次 deny 降 needApproval | 减少重复申辩 |
| 工作区记忆 | `clean()` 精确去重 + 条数上限 | C9 提取抑制 | 检索后对未选中近竞争项降权 | 关键决策不被挤出 |
| 前缀审计 | 只记「变了」 | C11 分歧点 | 记首个分歧段 + 字节偏移 | 修复优先级可排序 |
| 注入上限 | 条数上限 | C2 组块量 | 先定义组块，再按组块量限 | 上下文成本可控 |

**四条不动**，理由是「已经对了」或「改了更差」：

| 功能 | 为什么不动 |
|---|---|
| 红线 | 复合正则就是「多条件同时满足」，与 C1 的前馈抑制同构，**已符合** |
| L5 语义 | `modelSignal` 独立算 risk，不写阈值，与 C4 的标记通路同构，**已符合** |
| 环境 TTL | 事件计数型，但已声明「接受漂移」；改自持时钟的成本高于收益，**不采纳** |
| 重复拦截 | `repeatGuard` 是精确匹配，与 C3 的分离需求重合，**并入 C3 一起改** |

### C6 已核：前置不成立，撤出排期（2026-11-11）

原先的判据是「先确认部署环境真的注入了 model」。**核过了，答案是没注入**——而且原判据的描述也不准：

- `model` 不是模型 id，是第 5 层的**探针函数**（`checkEligibility.mjs:81`）。
- 三处真实调用点一个都不传：`eligibility-gate.mjs:276` 形参默认 `null`、`dsh/tools.mjs:72` 显式写死
  `model: null`、`dsh/guard/authz.mjs` 不传。于是 `checkEligibility.mjs:232` 的
  `typeof model === "function"` 恒假，第 5 层**整段跳过**。
- 原写「未注入时返回 `model-unavailable`」是错的：那个值只在**注入了函数但调用失败**时产生。
  未注入时 `modelSignal` 保持 `null`，连 `skip` 都不记。

所以 C6 的真正前置不是「确认注入」，而是「**先给第 5 层接探针**」——探针必须由宿主/适配层提供，
FG 自己没有调模型的能力，也不该为此把零依赖内核变成需要 API key 的东西。
探针接上之前，影子判定没有可补跑的对象。**撤出排期，不占版本位。**

### C8 不排期：数据不支持（2026-11-11）

上一轮把它排成「最该先动」，依据是「每步整份读改写 + 转义放大」。实测两条都不成立：

- 转义放大（347 MB / 202 行）是 2026-11-07 修的**历史事故**，`cell`/`uncell` 已配对。
- 现状体量：`CASE_FILE.md` **1,380 字节 / 29 行**，【三】零条记录；`workspace.json` **1,342 字节**。
  「整份读改写」的成本就是 1.4 KB。`CASE_MAX_ROWS=200` 封顶后也才约 24 KB。

省下的是毫秒与几 KB，不是 token。**等卷宗真长到接近 200 行再谈**，否则就是为假想负载加分支。

> 判据：一个优化的收益要能说清「省在哪个量纲上」。说「省 IO」但量出来是 1.4 KB，
> 那是把「看起来该优化」当成了「值得优化」。

## 维护（按版本位，不按日历）

| 版本位 | 动作 |
|---|---|
| 补丁位 `3.3.x` | 只改「状态」列，不做整页复核 |
| 变更位 `x.y.0` | 整页复核：十一条逐条问「失效模式还成立吗」 |
| 里程碑 `4.0` / `4.5` | 复核 + 重估「目标版本位」列 |
| 新增约束 | 必须同时给出失效模式与落点，缺一不收 |
| 想扩充脑区清单 | 除非出现第八类约束，否则不扩充 |

> **为什么不用日历**：日期是噪音，版本号本身才是进度刻度。
> 「连续 30 天未动」这类判据两头都误伤——长期不发版时该复核却不动，密集发补丁时不该整页复核却反复动。
> **版本位是离散刻度，正好对上改动强度**：补丁位改一行，变更位改一片。
