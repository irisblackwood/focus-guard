## 二、七层理论

理论不在单一学科里，是七层堆叠的「物理」。层间不是推导关系，是**约束关系**——每层说「不做会怎么坏」，不说「必须怎么做」。

| 层 | 尺度 | 核心内容 | 形式化 | 落到 |
|---|---|---|---|---|
| 〇 细胞 | 毫秒 | STDP：前后放电时序决定增强或削弱 | `Δw = A±·e^(−Δt/τ±)` | ✗ |
| 一 环路 | 十毫秒 | E/I 平衡与吸引子：单向判定没有稳态 | 能量极小值 | C1 |
| 二 系统 | 秒 | 自由能：持续存在的系统必然最小化惊讶 | `F = −ln P(o\|m) + KL[q‖p]` | ✗ |
| 三 调制 | 秒到分 | 四类调质＝四个元参数 | δ / β / α / γ | C5 |
| 四 意识 | 百毫秒 | 全局工作空间：点火 + 广播 | 非线性竞争 | ✗ 部分 |
| 五 身体 | 秒到分 | 躯体标记：稳态信号偏置选择 | 价值偏置 | C4 |
| 六 工程 | — | Mead：用物理，不模拟物理 | 三原则 | 禁令 |

### 〇 细胞层：STDP

- **内容**：同时放电的连接被强化；前后顺序决定方向，窗口几十毫秒。
- **它说了什么**：局部规则只靠时序就能产生方向性学习，不需要全局广播。
- **为什么不做**：本仓没有可塑权重，也没有毫秒级事件对。仿出来只有形状。
- **一处保留**：它证明了「低频全局信号足够」——这条支撑了 C5 的「学习不进执法」。

### 一 环路层：E/I 平衡

- **内容**：吸引子能存在的前提是兴奋与抑制比例被控制在临界区。兴奋过强全是癫痫，抑制过强全是沉默。
- **失效模式**：单一方向的判定器在状态空间里没有连续稳态，只有两个端点。
- **→ C1**：这是全套里唯一一条必要条件论证，不是工程偏好。

### 二 系统层：自由能原理

- **内容**：任何持续存在的系统必然最小化自由能（预测误差 + 模型复杂度）。
- **形式化**：第一项是拟合不足，第二项是复杂度——后者就是奥卡姆剃刀的信息论表述。
- **为什么不做**：不可证伪，且本仓没有生成模型，算不出 `P(o|m)`。
- **一处保留**：第二项（复杂度惩罚）为「主动遗忘」提供正当性，但那条 MDL 就够，不需要整个框架。

### 三 调制层：调质＝元参数

- **内容**：调质不是四种递质，是强化学习的元参数——探索温度、学习率、折扣、误差信号。
- **它说了什么**：调质是全局广播的慢变量，不参与任何一次突触传递，只改传递规则。
- **→ C5**：这正是「学习只调参、不进执法」的理论根。
- **两处如实修正**：
  - 对应关系原文用 **"may correspond"**——是推测，不是定论。
  - 二手引述只列了 **血清素、去甲肾上腺素、乙酰胆碱三个**；**多巴胺＝TD 误差来自 Schultz 等的另一条线**，不是同一次映射。

### 四 意识层：全局工作空间

- **内容**：脑是大量并行处理器，意识是窄带广播总线。进入意识＝点火：一个子集突然、相干、独占激活，同时抑制其余。
- **它说了什么**：用串行线程管理大规模并行资源。
- **✗ 部分**：并行竞争 + 点火式仲裁要求「差一票全输」，不可重放，与验收标准冲突。
- **一处保留**：本仓的串行流水线**就是**「串行线程管并行资源」的实现，不需要改成并行。

### 五 身体层：躯体标记

- **内容**：决策被内脏与躯体信号标记和偏置。杏仁核在做价值标记，不是染色剂。
- **→ C4**：标记（给事件打价值）与稳态（维持整体平衡）时间常数、失效模式都不同，必须两条通路。
- **读到摘要**：标记来自生物调节过程，不限于情绪；作用于多个层级，有显性也有隐性。

### 六 工程层：Mead 三原则

| 原则 | 内容 | 本仓对应 |
|---|---|---|
| 用器件物理 | 不跟物理对抗，用它的本征特性 | append-only 日志、文件哈希、进程隔离 |
| 空间局部性 | 布线是最贵的资源 | 模块依赖方向、少跨层调用 |
| 形态即计算 | 拓扑本身是计算的一部分 | 依赖方向即学习算法，不另造学习模块 |

- **它说了什么**：不模拟脑的形状，用脑的原理。
- **由此得出一条禁令**：照抄海马体/丘脑/半脑 = 抄形状 = 违反本层。

**实测比例**：50 个里 39 个是已有类或别名，5 个析出 C6/C7。边际收益在第 40 个之后接近零。

### 新析出的两类

| 类 | 脑区 | 约束 |
|---|---|---|
| 一致性监测 | 前扣带（冲突检测）、屏状核（跨模态绑定）、胼胝体（半球通信） | C6 |
| 时间基准 | 视交叉上核、松果体 | C7 |

**读到摘要**：ACC 的职能是「monitoring for conflicts」，且冲突信号**触发补偿性调整**——不只是记录，还驱动调整。
**推论**：C6 的影子判定除了留痕，也可作为调整的**触发源**，但仍不改当次决策。

### 为什么不按脑区建模块

| 理由 | 说明 |
|---|---|
| 分类本身不稳定 | 一份综述明说分类「still a work in progress」；另一份说模体数「至少与细胞类型一样多」 |
| 解剖相连的环路拆开就失效 | 基底节-丘脑-皮层是一个闭环，拆成两个模块两个都废 |
| 命名固化形状 | 形状会过期，名字会留坑 |

## 四、记忆机制

记忆不是一体，是四套系统；也不是「存储」，是**压缩**。

### 四套系统

| 系统 | 特征 | 本仓对应 |
|---|---|---|
| 工作记忆 | 容量约 4 组块，会话内 | 单会话上下文 / 预算 |
| 情景记忆 | 一次性、带时空索引 | 卷宗【三】取证 |
| 语义记忆 | 去情境、可复用 | 静态知识库 / 法条 |
| 程序记忆 | 无法言说、靠练习 | **无对应** |

### 三个过程

| 过程 | 机制 | 约束 |
|---|---|---|
| 巩固 | 离线重放，以**压缩格式**转移到皮层；情景只发生一次，重复由重放提供 | C10 |
| 再巩固 | 提取后需**预测误差**才变脆弱并重写 | C8 |
| 提取诱发遗忘 | 提取时**主动抑制**竞争记忆，是适应性的 | C9 |

### 两条定量事实

- **容量**：约 4 个组块。7±2 是「rough estimate and a rhetorical device」，不是上限。
- **边界条件**：容量限制只有在组块边界被定义清楚时才有意义。→ C2

### 一条反直觉结论

两篇（算子清单、巩固综述）都把记忆说成 `compression`，**没有一篇**说成「存储」。
所以「记忆模块」这个词本身是错的，它该叫**压缩通道**。

| 机制 | 内容 | 落到 |
|---|---|---|
| 中间神经元分工 | 三个主组 PV / SST / 5HT3aR；VIP 属 5HT3aR 亚组 | C1 |

| 增益控制两种形式 | 除法降斜率 vs 减法平移 | C5 |
| 树突分区 | 单神经元有独立积分区，局部非线性 | 禁令：复合条件不拆模块 |

### 三种抑制模体

| 模体 | 触发方式 | 本仓对应 |
|---|---|---|
| 前馈 | 多条件同时满足（巧合检测） | 红线（复合正则） |
| 反馈 | 按实际活动量累计 | **缺**（触发率不存在） |
| 去抑制 | 临时关掉抑制，不改阈值 | `fg_appeal` 一次性授权 |

**关键区分**：去抑制是局部、临时、留痕的；改阈值是全局、持久、不可回放的。两者不可互换。

## 六、明确不做的理论

| 理论 | 为什么不做 |
|---|---|
| STDP 时序加权 | 无权重、无毫秒事件对，没有消费者 |
| 自由能作为目标函数 | 不可证伪，无生成模型可算 |
| 并行竞争 + 点火仲裁 | 不可重放，违反验收标准 |
| 按脑区建模块 | 分类不稳定，零件表不可收敛 |
| 左右半球双脑投票 | 分裂决策，重放无法复现 |
| 突触级仿真 | 仿的是形状不是计算 |

## 八、理论地位

- **理论是脚手架**，不是物理学。不可证伪的框架只能给设计约束，不能给验收标准。
- **验收永远是工程指标**：误伤率降没降、审计能不能重放、崩了能不能恢复。
- **允许理论错**：某条约束被工程证伪时，改约束不改验收标准。
- **理论帮你在动手前少走弯路，但不替系统负责。**
