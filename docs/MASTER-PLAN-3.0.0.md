# 协作治理总纲（3.0.0）

> 十大原则 → 十项机制：中心调度、蜂群委派、去中心化验证、静态图书馆、积木拼装、本地哨兵、KPI 兑现、提问即治理、因果链追溯、开源收尾。
>
> （工程总纲，非法条；法条载体见 [RULES.md](RULES.md) 第十五章之二与相关条款，引擎 `hooks/guard.mjs` v3.0.0。研读依据引自本地明文库 `E:\DSH\vault-plain\`（密文正本在 `miniature-happiness-main` 仓）。）

## 一、定位

2.x 时代 FocusGuard 管的是**单会话的履职纪律**（取证、预算、锚点、高危）。3.0 把治理面扩展到**多代理协作与知识资产**：主会话怎么调度、子代理怎么回传、审计由谁做、知识放哪里、表现怎么兑现。不变量依旧：日常零打扰，只拦行为，全程留痕，人类批示至上。

## 二、十大原则 → 十项机制

### 1. 中心思维（主会话只做调度与审计）
- **依据**：R1 主题4"delegate and you keep the conclusion, not the file dumps"；R7 关键路径理论。
- **机制**：主会话定位=调度者+审计者。关键路径任务（下一步等它的结果）亲手做；sidecar 任务（可并行、可等待）一律委派。强制委派场景（11.3）已有引擎判定，本条补齐"委派期间主会话做什么"——立即做不重叠的实质工作，禁反射性等待（R7 §五）。
- **落地**：RULES 十五·二（一）；SKILL §13.1。

### 2. 蜂群思维（无状态子代理 + 摘要回传）
- **依据**：R7 §三（self-contained / disjoint write sets）；R2 T13（只读委派优先、三层只读执法）；R4 §七（fork 继承式 vs 新鲜式并存的显式区分）。
- **机制**：派单自包含（子代理不继承对话，上下文随派单给全量——R3-8：简洁规则不适用于子代理派单）；回传只收【子代理摘要】四字段（11.2 已机械化）；并行任务按互不相交写集分解；多 worker 共存三律（所有权明确/不回滚他人/适配他人）；委派默认只读，写权限按需显式开。
- **落地**：RULES 十五·二（二）；SKILL §13.2；引擎 delegate-used 事件带子链（见第 9 条）。

### 3. 去中心化验证（跨模型交叉审计，拒绝互评点头）
- **依据**：R5-5 advisor-tool（二级复核层，全库唯一：更强模型在"实质工作前/宣称完成前"复核）；R1 主题10 谄媚防护；R1 主题9 codex auto-review（findings first）。
- **机制**：关键决策（高危批准前、熔断宣告前、宣称完成前）引入**换模型互查**——审计不得由产出者自评；复核报告 findings-first（按严重度排序带 文件:行号），没发现问题须明说查了什么、残余风险是什么；"同意"不算复核发现，无锚点的互评一律视为点头。
- **落地**：RULES 十五·二（三）；SKILL §14。平台无法强制指定复核模型，本条属纪律条款（人工执行），列入未机械化清单的"纪律执行"栏。

### 4. 静态知识图书馆（动静隔离，避免污染动态卷宗）
- **依据**：R6 M6-1 Codex Memory 四机制（记忆更新隔离区：AI 只能往隔离区丢便签，不能直接改自己的知识库）；R1 主题6（索引与内容分离、查重删错）；R5-4 doctor（剪掉能自行推导的，保留 gotcha 与非标准约定）。
- **机制**：`.ai/library/` 为静态积木区：构建后不可变；引擎拦截直写（提示写 inbox/）；图书馆读不进卷宗【三】（积木指纹在 INDEX.md 固化，动态卷宗只管动态工作区）；免重读闸对积木不生效（积木粒度小，重读成本天然低）。
- **落地**：引擎 `LIBRARY_RE` 三处（直写拦截 / 免卷宗记账 / 免重读豁免）；`tools/library-build.mjs`。

### 5. 积木化拼装（把书拆成积木，把开发做成拼积木）
- **依据**：R6 M6-1 机器可解析引用（`MEMORY.md:行号|note=用法`——引用粒度到块）；R5-2 consolidate-memory（持久/时效分离、易重查的删、索引限额）。
- **机制**：`library-build.mjs` 把研读长文按 `##` 节拆成自包含积木（frontmatter：id/来源/sha256/tags），INDEX.md 一行一条指针；引用知识 = 引积木 id（如 `[经验:B003]`），不再整文搬运。开发同理：任务结论引用积木块而非重抄原文。
- **落地**：`tools/library-build.mjs`（幂等：同源同指纹保留原 id；源移除标 retired 不物理删）。

### 6. 本地零成本哨兵（Needle 2 替代 Jev，离线拦截）
- **依据**：R5-6 Computer-Use 风险分税制（特征库六类之外还有"代理性通信/敏感数据传输"两维）；R1 主题3 Grok 反绕过宣言。
- **机制**：`tools/sentinel.mjs` 离线预判命令风险（管道执壳/混淆绕行/外发数据/持久化通道/块设备直写等特征库未覆盖形态）。引擎内建启发式（零依赖零成本）；`--model-cmd` 可挂本地小模型 Needle 2（Cactus Compute 45M/14MB，工具调用与结构化 JSON 判定）做外判——替代云端判定方案（Jev）的本地化落点，离线即拦截，模型失败静默回退启发式。引擎接入 opt-in：`FG_SENTINEL=1`（默认 audit-only 只记档；`FG_SENTINEL_MODE=strict` 升级拦截）。
- **落地**：`tools/sentinel.mjs`；guard.mjs pre 模式哨兵层。
- **注**：Jev 无本地出处可考，本机制按"云端判定→本地零成本"的替代目标实现，接口可插拔。

### 7. KPI 兑现闭环（不再是记分牌，而是真正的考核奖惩系统）
- **依据**：RULES 二十七~三十二条（考核等次/奖惩/跨任务累计）原列"未实现"；表4 已有等次口径。
- **机制**：Stop 收尾即结算——本任务 KPI → 等次（≥+15 优秀 / 0~+14 称职 / -9~-1 基本称职 / ≤-10 不称职）→ 委托池奖惩（+5 / 0 / -2 / -5，下限 0）→ `kpiCarry` 跨任务累计落台账。执行池增减仍由人类批示（批示至上不变）；KPI ≤-10 保留一次性提醒。AUDIT 记 `kpi-settle`（ref 指向 stop-fired）。
- **落地**：guard.mjs stop 模式结算块；RULES 十五·二（四）；表4 增机械化注记；未机械化清单更新（等次+委托池奖惩已机械化，立功减刑仍人工）。

### 8. 提问即治理（漏斗式下发任务，避免空洞指令）
- **依据**：R1 主题5 澄清经济学（Grok 三问判据、Codex"elapsed time is not an approval"）；R4 §六（提问工具化共识）；R2 T15 Jules 两段式批准。
- **机制**：任务下发漏斗——治理目标 → 约束（禁区/预算）→ 验收锚点（什么信号算完成）→ 额度批示。空洞指令（无验收锚点）主会话不得硬猜：按三问判据（毁灭性？歧义无法自查？只有人类知道？）澄清后再动。计划批准 ≠ 实现批准：批示开工不豁免【提交申请】。
- **落地**：RULES 十五·二（五）；SKILL §15、§10.5 增补。

### 9. 因果链追溯（日志从流水账变因果图）
- **依据**：偷师 Semantica（图原生记忆层：因果链追溯 + 溯源 + Knowledge Explorer）。
- **机制**：AUDIT.log（JSONL）每条增三字段：`seq`（时间戳36进制.调用内序号，全局唯一）、`chain`（任务链，reset 起新链 T*，会话启动 S*，子代理派生 `/dN` 子链）、`ref`（父事件 seq）。`tools/audit-chain.mjs` 按链重组渲染因果树/因果图（--mermaid 直接进 Markdown）。旧格式日志兼容（无 seq 视为流水账，明确提示不虚构链）。
- **落地**：guard.mjs `audit()`/`auditChainInit()`；委派事件挂子链（ref 指回派单）；`tools/audit-chain.mjs`；表6 增三字段。

### 10. 开源工程化收尾（CHANGELOG + Git 历史整理 + README 重定位）
- **机制**：git 初始化 + 按逻辑单元结构化提交；CHANGELOG 3.0.0 依例记录（含破坏性变更申报：AUDIT.log 格式追加字段、解释器 eval 不再算只读侦查）；README 增加 3.0 协作治理章与工具表；版本五处清单 + ENGINE_VERSION 同步 3.0.0（验收锁定）。
- **随批修复**（deep-review-v2.5.3 修复优先级"随下个补丁"项）：FG-D1（授权引文核验 500 字符窗口截断致误伤——核验窗口扩至 4000 字符）；FG-D2（卷宗【一】改原子写）；FG-D3（tmp 残片清理对齐 saveState）；FG-D4（卷宗初始化包防御降级继续）；R5-3 采纳（解释器 `-c/--eval` 不再判只读侦查——堵熔断期白名单放行解释器的洞）。
